# 李杜同聲

**线上：https://cyberpiggy0419.github.io/li-du-cp/**

全唐诗里李白与杜甫的诗句相似度可视化。纯静态、零依赖、零构建：双击 `index.html` 就能看。

**四个页面**

| 页面 | 深链 | 内容 |
|---|---|---|
| 总览 | `#/overview` | 最高相似对、数据规模、相似度分布直方图、最像的十对、用字对照、互寄诗、方法与局限 |
| 句对 | `#/pairs` | 22,613 对相似句的检索：关键词、相似度下限、排序、范围过滤；共字高亮 |
| 精读 | `#/close` | 相似度 ≥ 0.85 的 154 对，字符级 diff 标出差异，按「同一句 / 差一字 / 差两字 / 差三字以上」筛选 |
| 演示模式 | `#/close?stage=1` | 全屏单条展示，← → 翻页、Esc 退出，答辩时可直接用 |
| 对读 | `#/read?poem=28383` | 选一首诗，逐句列出对方诗里的相似句；点任意一句继续跳转 |
| 猜一猜 | `#/game` | 随机抽一句猜作者，按键 `1` / `2` 作答 |

## 本地运行

```bash
cd li-du-cp
python -m http.server 8412
# 打开 http://127.0.0.1:8412
```

直接双击 `index.html` 也可以：数据编译成 `assets/data.js` 里的 `window.LD`，用 `<script>` 加载，不经过 `fetch`，所以 `file://` 下不会被 CORS 拦。

## 目录

```
index.html            页面骨架（静态部分 + 五个 section）
assets/style.css      全部样式（纸墨配色，无外部字体依赖）
assets/app.js         全部逻辑（原生 JS，无框架）
assets/img/           配图（杜甫推李白漫画，背景已抠成透明，webp + png 双份）
assets/data.js        ⚠ 生成物，由 build_data.py 产出，不要手改
build_data.py         数据编译脚本
```

## 数据

输入三份 CSV（默认从 Hermes 附件目录读取，用 `--src` 指到别处）：

- `李白.csv` / `杜甫.csv`：`诗题, 诗句, 诗ID, 句内序号`（无表头）
- `李白-杜甫.csv`：`李白, 题, 句, 杜甫, 题, 句, 相似度×10000, 李诗ID, 李句序, 杜诗ID, 杜句序`（无表头）

重建：

```bash
python build_data.py --src "C:/path/to/csv" --out assets/data.js
```

脚本做的事：

1. 按 `诗ID` 归并成诗，句序排序；
2. 校验配对里的诗 ID / 句序是否越界，越界的行丢弃；
3. 相似度是 0–10000 的整数（实际范围 7000–10000，即 0.70–1.00 的截断），除以一万展示；
4. 合并句面完全相同的重复行：原始 23,448 行里有 835 行来自《全唐诗》重复收录（例如《蜀道难》同时存在于「相和歌辞」类目），合并后 **22,613 对**；
5. 生成 0.70–1.00 的 31 格直方图、用字频率（每万字、去标点、两边各≥15 次才比较）、互寄诗清单。

## 关于数字的几句话（写论文时用得上）

- 相似度是**字面重合度**，不是风格相似，也不是影响关系。0.70 这一档（占 75%）主要靠常用字撑起来，读的时候当线索，别当结论。
- 「像」有两种：同一句诗被两家重复收录（`百里见秋毫` 同时见于李白《观放白鹰》与杜甫《山寺》，相似度 1.0000），以及真正的同声（`何时一杯酒` / `何时一尊酒`）。前者是文献问题，后者才是诗学问题——站点的前十对里两类都有，正好可以当作讨论的引子。
- 杜甫怀李白的 8 首诗里，与李白本人最高相似度是《春日忆李白》的 0.9429。这个数字本身很适合作为「杜甫用李白的词写李白」的例证：思念的修辞是从被思念者的语言里借来的。
- 用字对照只统计频次差（李白：绿、笑、梦、霞；杜甫：老、近、衰、峡），能说明语汇偏好，不能说明诗风高下。

## 可以继续做

- 只保留 ≥0.85 的「强相似」子集，单独做一个精读页
- 按体裁（乐府 / 五律 / 七绝）或创作时期分组，看相似度随时间的变化
- 同一套指标对照第三位诗人（王维、孟浩然），把「李杜」放进更大的网络
- 句对导出为 CSV / 图片，方便放进幻灯片
